# Manka weboldal képek

Ide kerülnek a Manka Fejlesztő Kuckó saját, jóváhagyott fotói.

- `manka-fooldal.webp`: címlap fő fotó (ideális legalább 1400 x 1400 px, közel négyzetes)
- `manka-csapat.webp`: bemutatkozó kép a foglalkozásról/helyszínről (ideális legalább 1200 x 1100 px)

A weboldal ezeket automatikusan betölti, amikor léteznek. Ha még hiányoznak, az illusztrált fotóhelyek látszanak.

Forrásmappa: https://drive.google.com/drive/u/0/folders/16BvpiP4Y4kHvscti4uGB2r5cDPahPLzb

Fontos: gyermekekről készült fotók publikálásához megfelelő jogalap, és adott esetben a törvényes képviselők szükséges hozzájárulása kell.
